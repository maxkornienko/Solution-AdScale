# C4-PlantUML (вендорная копия)

Этот каталог — **не наш код**. Здесь лежит копия библиотеки макросов
[C4-PlantUML](https://github.com/plantuml-stdlib/C4-PlantUML), распространяемой
по лицензии MIT (см. [LICENSE](LICENSE)).

| | |
|---|---|
| Источник | https://github.com/plantuml-stdlib/C4-PlantUML |
| Версия | 2.15.0beta1 |
| Лицензия | MIT |

Править файлы в этом каталоге не нужно: при обновлении библиотеки правки потеряются.
Обновление делается заменой файлов на свежие из upstream.

**Важно:** файлы библиотеки по умолчанию подгружают свои внутренности из интернета.
Чтобы использовалась эта локальная копия, рендер нужно запускать с флагом
`-DRELATIVE_INCLUDE=1` — подробнее в [README проекта](../README.md).
