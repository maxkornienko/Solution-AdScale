# Task1. Архитектурная диагностика и целевое видение AdScale

AdScale – SaaS-платформа для RTB-рекламы. Интеграция с новым DSP-партнёром поднимает нагрузку до 18 000 RPS через 3 месяца и требует ответа не дольше 80 ms; через год – 50 000 RPS, микросервисы и SLA 99,9%. Текущая система – гибридный монолит с единственной PostgreSQL – уже не укладывается в требования: P95 110–120 ms при норме 100 ms.

## Ключевые решения

- Приоритет атрибутов качества: производительность → надёжность → доступность → масштабируемость.
- Стратегия эволюции: в первые 3 месяца – модульный монолит и read replica для аналитических запросов; до конца года – микросервисы через Strangler Fig.
- Целевая архитектура: API Gateway как единая точка входа, gRPC внутри, Kafka для показов и кликов, Redis для кеша ставок, кампаний и разметки, своя БД у каждого сервиса, где она нужна.
